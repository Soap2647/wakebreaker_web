# Wakebreaker Web

The web-specific portal for the Wakebreaker project. Developed utilizing Flutter for Web, this repository focuses on delivering a responsive, browser-optimized experience. It brings the core functionalities of Wakebreaker to any device with a modern browser without requiring an installation.

## Features
- **Browser Optimized:** Specifically tailored for web performance and compatibility.
- **Responsive Layout:** Automatically scales from desktop to mobile browsers.
- **Single Page Application:** Fast navigation without page reloads using Flutter's web engine.

## Technologies Used
- **Flutter (Web)**
- **Dart**

## Setup and Execution
1. Ensure the Flutter SDK is installed and web support is enabled.
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the web server:
   ```bash
   flutter run -d chrome
   ```
